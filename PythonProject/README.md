# Customer Churn Prediction

A Machine Learning project to analyze telecom customer data, identify factors associated with customer churn, and predict whether a customer is likely to churn.

## 📌 Project Overview

This project uses the Telco Customer Churn dataset containing **7,043 customer records**.

The project includes:

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Statistical analysis
- Feature engineering
- Machine Learning model training
- Model evaluation
- Customer churn prediction

## 📊 Dataset

- **Records:** 7,043
- **Original Features:** 21
- **Final Features:** 34
- **Target Variable:** Churn

The target variable indicates whether a customer has churned (`Yes`) or stayed (`No`).

## 🔍 Exploratory Data Analysis

The project analyzes customer churn based on factors such as:

- Contract type
- Tenure
- Monthly charges
- Total charges
- Payment method
- Paperless billing

Statistical tests were also performed to identify relationships between important customer attributes and churn.

## 🤖 Machine Learning

Multiple Machine Learning approaches were evaluated for customer churn prediction.

### Best Model

**Logistic Regression**

- **Accuracy:** 80.27%

The final trained model and preprocessing files are included in the project.
